# lionelmessi

**Scientific football analytics for Lionel Messi's career.**

`lionelmessi` ingests [StatsBomb Open Data](https://github.com/statsbomb/open-data)
and delivers:

- pitch-level spatial analytics,
- **Expected Threat (xT)** and VAEP-style action values,
- possession-chain ("continuation") analysis,
- goal and assist breakdowns, and
- publication-quality visualizations.

## Install

```bash
pip install lionelmessi
```

!!! note "Data & ethics"
    The package consumes StatsBomb Open Data (free, non-commercial). It is not
    affiliated with, endorsed by, or sponsored by Lionel Messi or StatsBomb.

See [Quickstart](quickstart.md) to get running in under a minute.
